# Day 22 - Responsive Information Page

## What I did

- Built a responsive information page in day-22/index.html
- Linked it to ../styles.css at the root

## How I tested it

- Opened it in Brave with Live Server
- Wide: nav links in a row, sections in boxes
- Narrow, 375px in DevTools: nav links stacked, page readable, no sideways scroll

## What I learned

- The viewport meta tag tells the browser the page width matches the device
- A media query changes the CSS at 600px wide or less
- ../ in a link means go up one folder
