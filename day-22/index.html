Day 22 - Responsive Information Page

What it is How it works How I tested it

What it is

A responsive page changes its layout to fit the screen it is on.

Wide screens show links in a row. Narrow screens stack them.

How it works

The viewport meta tag tells the browser the page width matches the device width.

A media query changes the CSS when the screen is 600px wide or less.

How I tested it

I opened the page in Brave with Live Server.

I used DevTools to test it wide, then at 375px narrow.

Wide: nav links in a row. Narrow: nav links stacked, page readable.
